# Protocol references and attribution

Inspected 31 October 2026; pinned source revisions:

- [Checkpoint GbaSave, 740f221](https://github.com/FlagBrew/Checkpoint/blob/740f221a853db784401458fe74276977afcfa8b0/3ds/source/gbasave.cpp): `AgbSaveHeader`, `calcSlotCmac`, `locateCurrentSlot`, `restore`. Header is 0x200 bytes; CMAC is at 0x10; hash starts at 0x30 and covers header remainder plus declared raw save. Retain console SD CID/title metadata. The file-bound `FSPXI_CalcSavegameMAC` provides console-specific authentication. Its result can initially be stale.
- [Checkpoint FSStream at the same revision](https://github.com/FlagBrew/Checkpoint/blob/740f221a853db784401458fe74276977afcfa8b0/3ds/source/fsstream.cpp): binary file path `{1,1,3,0,0}`, exact byte counts, `FS_WRITE_FLUSH` on PXI writes.
- [PKSM loader, 9cad156](https://github.com/FlagBrew/PKSM/blob/9cad15694c1e90cc058ddd285eb68d56c7ad9ac8/3ds/source/titles/loader.cpp): `calcGbaSaveSHA256`, `calcGbaCMAC`, load/save GBA branches. Documents the service's nested CTR-SAV0 / CTR-SIGN hashing and AES-CMAC; **do not apply those layers a second time before calling the service**. PKSM checks existing MACs and can save into the older slot with an incremented counter.

Phase 14 is an original, deliberately more restrictive implementation, not an upstream Checkpoint/PKSM release. Protocol inspiration is credited to Bernardo Giordano, FlagBrew and PKSM contributors. New code is GPL-3.0-or-later. Unlike Checkpoint's current-slot restore, this prototype preserves the current slot and stages into the older slot, drawing on PKSM's alternating-slot approach. Unlike either retry loop, exhaustion without two consecutive equal successful MACs is an explicit error. These design differences need independent console validation.

`vendor/sha256.c` and `.h` are Brad Conte's SHA-256 implementation as carried in Checkpoint at the pinned revision. Original notices are retained. The [original author's licensing statement](https://github.com/B-Con/crypto-algorithms/blob/master/README.md) releases it into the public domain. Modified here: cast input bytes to unsigned WORD before left shifts in `sha256_transform`, fixing UBSan-detected undefined signed overflow. This hash is used on public/save data; secret-key AES-CMAC remains exclusively in the console service, not this vendored code. Known-answer tests cover empty input, `abc`, and one million `a` bytes.
