## Blockers — do NOT overclaim
- Full PKSM Rogue graphical editor has NOT been shown navigable in a working emulator. Phase 9.4 is a separate extdata-free native text-console editor whose writes are restricted to the exact synthetic fixture; real game saves remain read-only. Both untouched official PKSM 10.4.2 and the fork show the same extdata-initialization warning in a fresh Azahar profile (control: https://github.com/hboots999-hash/Rogue-save-editor-/actions/runs/41156495959). This does not establish a defect in Rogue code or a device-safe bypass.
- Exact patched Emerald Rogue ROM/build mapping is unknown. Synthetic/candidate save tests do not establish valid in-game behaviour for all edits, item IDs, hub flags or upgrades.
- Direct 3DS installed-game archive backup/recovery, restoration and launch/exit testing are unverified. Previous experimental standalone RogueSM CIA reportedly caused a HOME Menu data abort on the user's physical console.
- Species/ability/nature/held-item/PC/hub upgrade editing is not MVP-complete. Phase 9.3 does support synthetic-only fixed IV/EV/move presets, but **still refuses ALL real-game save drafts** until exact patched-ROM compatibility is verified.
- **DO NOT install the experimental CIA on the user's physical 3DS, delete/reset PKSM extdata, write to live VC save, or distribute a "final" release.**
- GitHub Actions artifacts are temporary (7-day retention in these workflows). Permanent source is in the branch; this HANDOFF note, source archive and patches survive individual artifact expiry.
